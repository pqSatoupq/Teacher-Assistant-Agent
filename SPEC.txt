# Project Name: Teacher Assistant Agent
# Tech Stack: Python, Streamlit (for a simple web UI), SQLite (database), Google Gemini API (google-generativeai SDK), python-docx (for Word export)

## Project Goal
Build a local web application that allows a teacher to generate structured, formal documents from messy, casual input text. 

## Core Features
1. **Simple Web UI (Streamlit):** 
   - A dropdown to select the "Task Type" (e.g., "Official Memos (บันทึกข้อความ)", "Lesson Plans", "Letters to Parents", "Project Proposals", "Meeting Minutes").
   - A large text box for the user to type or paste rough notes.
   - A "Generate Document" button.
   - A display area to show the final generated Markdown document.
   - An "Export to Word (.docx)" button so the teacher can download the final document for printing, formatting, and signing.
   - A "Settings" menu or sidebar where the user can set, change, or add new API keys and select which AI model to use.

2. **AI Agent Logic (Flexible API):**
   - Support calling AI models based on user-provided API keys (e.g., Google Gemini as primary, with options to extend).
   - *API Key Management:* Allow users to select the AI model associated with their key. (If supported by the specific provider's API, optionally attempt to display remaining tokens/credits, though this is a low-priority feature).
   - Use system instructions to strictly control the output based on the selected "Task Type".
   - *Language and Tone:* System instructions must enforce formal Thai official language (ภาษาราชการ) and proper bureaucratic terminology when generating documents for Thai school contexts.

3. **Database Integration (SQLite):**
   - Automatically save a record of every generated document into a local `documents.db` file.
   - The database table should store: `id`, `date_created`, `task_type`, `original_notes`, and `generated_document`.
